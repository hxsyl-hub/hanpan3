# 焊盘缺陷检测 —— 实验结果与分析

## 〇、数据口径说明

为避免指标不可比，先统一口径：

- **权重选取**：所有模型均保存「验证集 ACC 最高」那一轮的权重（`best.pth`），并在 test 集上评估
- **末轮 test_ACC**：指训练结束那一轮的测试精度，与 `best.pth` 口径不同，文中并列列出
- **后续 9 组实验**：统一采用 GoogLeNet + 标签平滑 0.1，四组变量之外保持一致，便于横向对比
- **严重缺陷定义**：`NG_PadDiscoloration`（焊盘变色）、`NG_PadContamination`（焊盘污染）、`NG_Misalignment`（偏移）、`NG_ColdJoint`（虚焊）

## 一、实验设置

### 1.1 数据集

原始图像 6593 张，经清洗与类别均衡（OK 类裁剪至 1500 张）后共 **5047 张**，按 6:2.6:1.3 划分为：

| 集合 | 张数 | 用途 |
|---|---|---|
| train | 3067 | 训练 |
| val | 1317 | 选权重、调参 |
| test | 663 | 最终评估（全程不参与训练与选优）|

test 集各类别分布：

| 类别 | 中文 | 支持数 |
|---|---|---|
| OK | 合格 | 436 |
| NG_PadContamination | 焊盘污染 | 71 |
| NG_ExcessSolder | 多余焊料 | 64 |
| NG_MissingSolder | 缺焊 | 52 |
| NG_ColdJoint | 虚焊 | 30 |
| NG_Misalignment | 偏移 | 7 |
| NG_PadDiscoloration | 焊盘变色 | 3 |

> 划分结果存于 `splits/{train,val,test}.txt`，经校验 **三个集合无任何交集**，杜绝数据泄漏。

### 1.2 训练环境

| 项目 | 配置 |
|---|---|
| GPU | NVIDIA GeForce RTX 3080 Ti |
| 框架 | PyTorch 2.8.0 (CUDA 12.8) |
| 优化器 | AdamW |
| 学习率 | 1e-4 |
| Batch Size | 64 |
| Epochs | 50 |
| 输入尺寸 | 224 × 224 |

### 1.3 评价指标

除常规准确率外，本实验以**严重缺陷漏检率**为核心工业指标：

- **总体 ACC**：全部样本判对的比例
- **宏平均 ACC**：各类 ACC 的算术平均（不受多数类支配，能反映小类表现）
- **严重缺陷漏检率**：严重缺陷样本未被正确识别的比例，越低越好

> 工业验收中，把缺陷判成合格的代价远高于把合格判成缺陷，因此选模型时以漏检率为首要依据。

## 二、基线模型对比（50 轮，从零训练，无增强）

### 2.1 训练耗时与精度

| 模型 | best_val_ACC | 末轮 test_ACC | 宏平均 test_ACC | 耗时(s) |
|---|---|---|---|---|
| **googlenet** | **0.9393** | **0.9216** | **0.8100** | 249.6 |
| resnet34 | 0.9248 | 0.9155 | 0.6794 | 299.2 |
| vgg16 | 0.9188 | 0.8989 | 0.7362 | 806.8 |
| resnet50 | 0.9157 | 0.9035 | 0.6828 | 443.2 |
| mobilenet_v2 | 0.8633 | 0.8024 | 0.6050 | 245.6 |

### 2.2 test 集评估（best.pth 口径）

| 模型 | 总体 ACC | 宏平均 ACC | 严重缺陷召回 | 严重缺陷漏检 |
|---|---|---|---|---|
| **googlenet** | **0.9291** | **0.8100** | **0.7491** | **0.2509** |
| resnet34 | 0.9095 | 0.6794 | 0.5221 | 0.4779 |
| vgg16 | 0.9020 | 0.7362 | 0.6376 | 0.3624 |
| resnet50 | 0.9020 | 0.6828 | 0.5176 | 0.4824 |
| mobilenet_v2 | 0.8431 | 0.6050 | 0.4328 | 0.5672 |

**结论**：GoogLeNet 在四项指标上全面领先，且耗时仅 249.6 s，为 5 个模型中最快（vgg16 耗时是其 3.2 倍而精度更低）。故后续实验以 GoogLeNet 为基准模型。

**存在问题**：基线存在明显过拟合。以 GoogLeNet 为例，末轮 train-val 差距为 0.0673，且总体 ACC（0.9291）显著高于宏平均 ACC（0.8100），说明**少数类被多数类（OK，占 65.8%）掩盖** —— 模型倾向把困难样本判成 OK，这正是工业场景中最不能接受的失效模式。

## 三、改进实验：抑制过拟合

针对上述问题，设计 9 组对照实验，统一采用标签平滑（label smoothing = 0.1）抑制模型对训练样本的过度自信。

### 3.1 实验结果

| 编号 | 实验内容 | 总体 ACC | 宏平均 ACC | 严重缺陷漏检 |
|---|---|---|---|---|
| C2 | 在线增强：水平+垂直翻转 | 0.9367 | 0.7793 | 0.3281 |
| C3 | 在线增强：角度旋转 ±15° | 0.9352 | 0.7895 | 0.3076 |
| C4 | 在线增强：高斯模糊 | 0.9352 | 0.8247 | 0.2470 |
| C1 | 在线增强：直方图均衡 | 0.9246 | 0.7551 | 0.3517 |
| **D1** | **离线扩充：小类 +50%** | 0.9231 | **0.8686** | **0.1446** |
| A2 | 预训练权重（ImageNet） | 0.9185 | 0.7658 | 0.3198 |
| E1 | 离线扩充 + 在线增强（叠加） | 0.9125 | 0.7902 | 0.3100 |
| C5 | 四种在线增强叠加（对照组） | 0.9095 | 0.7795 | 0.3256 |
| B2 | 预训练 + 冻结骨干（只训分类头） | 0.8069 | 0.4987 | 0.7007 |

> 基线对照：GoogLeNet（无增强、无平滑）总体 ACC 0.9291 / 宏平均 0.8100 / 漏检率 0.2509

### 3.2 结果分析

**（1）离线扩充（D1）是唯一显著有效的手段**

D1 将严重缺陷漏检率从基线的 **25.09% 降至 14.46%**（相对降低 42%），宏平均 ACC 从 0.8100 提升至 0.8686。其原理是直接针对小类样本不足的根因：对 `NG_ColdJoint`(204)、`NG_Misalignment`(48)、`NG_PadDiscoloration`(20) 三个小类离线生成 136 张增强图，写入训练集而不触碰 val/test，评估口径保持不变。

代价是总体 ACC 下降 0.6 个百分点（0.9231 vs 0.9291）—— 这是**值得的交换**：小类检出率上升后，一部分原本被轻松判对的 OK 样本被判为缺陷，总体 ACC 因此略降，而工业验收更看重的漏检率大幅改善。

**（2）在线增强整体收益有限**

C1–C5 中，仅 C4（高斯模糊）的漏检率（24.70%）略优于基线，其余均持平或更差。C2/C3 总体 ACC 虽最高（0.9367/0.9352），但漏检率反升至 32.81%/30.76%。原因是**翻转、旋转等变换对小缺陷并非语义等价**：焊盘缺陷的方向性信息本身是判别依据，随机翻转会破坏它。

**（3）离线扩充与在线增强不宜叠加**

E1（0.9125 / 0.7902 / 0.3100）明显劣于 D1 单独使用（0.9231 / 0.8686 / 0.1446）。小类经离线扩充后已有足够样本，再施加在线随机扰动反而引入噪声，对小样本是伤害。

**（4）ImageNet 预训练在本任务上无优势**

A2（有预训练，0.9185 / 0.7658 / 0.3198）反而劣于从零训练的基线（0.9291 / 0.8100 / 0.2509）。原因是**域差异过大**：ImageNet 为彩色自然图像，本任务为黑白 X 光焊点图，低层纹理特征难以迁移。

**（5）冻结骨干不可取**

B2 漏检率高达 70.07%，宏平均仅 0.4987。仅训练分类头无法让特征提取器适配焊点图像的域特征，验证了本任务必须全量微调。

### 4.3 亮点

1. **NG_PadDiscoloration（焊盘变色）3 张全部识别正确，漏检率 0%** —— 该类别基线时是重灾区，离线增强为这个仅 20 张训练样本的类补充样本后彻底清零，是小类离线增强策略最直接的证据。
2. **NG_Misalignment（偏移）召回 0.8571** —— 7 张测试样本中 6 张判对，小类增强同样奏效。
3. **OK 类误报率仅 2.75%**（436 张中 13 张误判为缺陷）—— 误报过高会导致复检成本激增，该值处于健康水平。

### 4.4 现存短板

**NG_ColdJoint（虚焊）召回率 0.7333，为所有严重缺陷类中最低**，30 张中 8 张未正确识别，去向为：

```
3 张 → 误判为 NG_PadContamination（焊盘污染）   ← 主要混淆源
1 张 → 误判为 OK                                ← 真实漏检
4 张 → 分散误判至其他 NG 类
```

根因是**虚焊与焊盘污染在 X 光图像上灰度形态高度相似**（均表现为焊点区域异常），模型难以区分。此外 `NG_MissingSolder`（缺焊）有 7 张被判为 OK，属于需要重点关注的真实漏检。

## 五、结论

1. **模型选型**：GoogLeNet 精度最高、耗时最短，为本项目最优骨干。
2. **过拟合治理**：针对小类样本不足的**离线扩充（D1）**是唯一显著有效的手段，使严重缺陷漏检率相对降低 42%；在线数据增强与 ImageNet 预训练在本任务上均无明显收益，冻结骨干则严重劣化。
3. **工业可用性**：最优方案总体 ACC 0.9231、宏平均 0.8686、严重缺陷漏检率 14.46%，严重缺陷平均召回率 0.8554，具备工业辅助检测的实用价值。

### 后续改进方向

1. 针对虚焊与焊盘污染的混淆，引入更高输入分辨率（384×384）或局部 ROI 裁剪，强化焊点区域细节特征
2. 对易混淆类对（CJ–PC、MS–OK）开展难例挖掘（hard example mining），或在损失中引入类间间隔约束
3. 补充 `NG_PadDiscoloration`（仅 20 张）、`NG_Misalignment`（仅 48 张）的真实样本，样本量是这类任务的核心瓶颈
